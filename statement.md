# Project Statement

## Project Title
Campus Expense & Budget Manager

## Problem Statement
Students make frequent small payments for food, transportation, study materials, subscriptions, and other campus-related needs. Without systematic tracking, it is difficult to identify spending patterns and determine whether a monthly budget is being exceeded.

The proposed system is a command-line Java application that records expenses, maintains monthly budgets, stores data persistently, and generates simple spending reports.

## Scope
The project covers:
- Expense creation, viewing, and deletion
- Monthly budget configuration
- Budget usage monitoring
- Category-wise monthly reports
- Persistent CSV storage
- Input validation and error handling

The current version does not include online payments, banking integration, authentication, or cloud synchronization.

## Target Users
- College students
- Hostel residents
- Students managing monthly allowances
- Users who prefer a lightweight terminal-based expense tracker

## High-Level Features
1. Add an expense with date, category, amount, and description.
2. View all recorded expenses.
3. Delete an expense by ID.
4. Set a monthly spending limit.
5. Check current-month budget usage.
6. Generate category-wise spending reports.
7. Persist expense records using CSV.
8. Validate user input and handle errors safely.
